# Проект: веб-чат для студентов Международного университета Астаны (AIU Chat)

Общение с пользователем — на русском языке.

## Правила работы

### 1. Вопросы вместо догадок
- Если чего-то не знаешь о продукте, пользователях, функциях или требованиях — не придумывай, спроси.
- Вопросы задавай порциями по 3–5 штук, коротко, с вариантами ответа, где это возможно.
- Решение по умолчанию (например, стек) предлагай явно: «предлагаю X, потому что Y, согласен?».
- Не начинай писать код, пока пользователь не подтвердил план.

### 2. Разделение моделей
- Планирование, архитектура, разбор требований и проверка кода — в основной сессии (Opus 5.5).
- Код пишет только субагент `coder` (`.claude/agents/coder.md`, model: sonnet).
- Сам код в основной сессии не пиши — передавай задачи агенту `coder`.
- Основная сессия проверяет результат `coder` (ревью) до того, как считать задачу выполненной.

### 3. Порядок работы
1. Задать уточняющие вопросы по ответам пользователя.
2. Составить план и архитектуру в `docs/PLAN.md`: стек, структура, функции MVP, этапы.
3. Ждать явного «ок» от пользователя.
4. Разбить план на маленькие задачи и выполнять по одной через `coder`; после каждой коротко сообщать, что сделано.

## Контекст продукта (из ответов пользователя)
- Веб-чат типа Telegram для студентов AIU (Казахстан) из разных курсов: помочь с экзаменами и вопросами по предметам, общение со старшими курсами.
- Сообщения: текст, фото, видео, голосовые, ссылки.
- Группы/подкатегории по предметам (например «Алгоритмы и структуры данных»), публичные: находятся через поиск, можно вступить самому, можно делиться ссылкой-приглашением.
- MVP: регистрация и вход (Google или e-mail), главный экран, основной чат в реальном времени. Оплаты нет.
- Адаптивная веб-версия (десктоп и мобильный браузер); мобильного приложения нет.
- База данных: Supabase. Хостинг: бесплатно, без своего домена (ссылка вида *.vercel.app), для демонстрации преподавателю и студентам.
