# supabase/ops

Служебные SQL-скрипты для администрирования. Они НЕ входят в миграции и не выполняются автоматически: запускайте вручную в Supabase (**SQL Editor → New query**, вставить файл целиком, **Run**).

| Файл | Что делает |
|---|---|
| `cleanup_test_data.sql` | Удаляет тестовых пользователей `e2e+%@example.com`, их группы и личные чаты, файлы в Storage. Сначала показывает предпросмотр. Необратимо. |
| `demo_admin.sql` | Назначает `begzat.dev@gmail.com` admin во все демо-группы без админа. Запускать после очистки. |

Порядок перед показом: `cleanup_test_data.sql`, затем `demo_admin.sql`. См. [docs/DEMO.md](../../docs/DEMO.md).
